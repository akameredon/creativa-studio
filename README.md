# Creativa Studio

A free-core-forever creative design and visual content platform.

Creativa Studio is an open-development project for a professional, approachable graphic design editor and creative production workspace. The initial release prioritizes a genuinely useful, editable design canvas before advanced AI, collaboration, or marketplace features.

## Product principles
- Core manual design remains free forever.
- No mandatory subscription or watermark on user-created exports.
- AI is optional; the editor must work without paid AI services.
- Projects remain editable and user-controlled.
- Privacy, accessibility, mobile usability, and honest feature status are non-negotiable.
- No paid infrastructure or destructive data operations without explicit approval.

## Project status
**Stage:** Foundation / Phase 0  
**Current milestone:** Architecture and repository foundation  
**Not yet implemented:** Production editor, authentication, persistence, AI integrations, export pipeline.
