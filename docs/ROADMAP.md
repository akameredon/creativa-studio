# Creativa Studio — Implementation Roadmap

## Phase 0 — Foundation
- [ ] Confirm repository governance and license
- [ ] Confirm Supabase organization and project cost
- [ ] Select region and isolated backend
- [ ] Initialize Next.js/TypeScript application
- [ ] Add lint, typecheck, test, and build checks
- [ ] Define canonical design-document schema
- [ ] Add architecture decision records

**Exit:** clean build, CI passing, isolated backend confirmed, no secrets committed.

- [ ] Local recovery
- [ ] PNG export

**Exit:** user can create, edit, save, reopen, and export a complete design on desktop and mobile.

## Release discipline
Each phase requires evidence: implemented paths, tests run, build result, known defects, security review, and deployment verification. A feature is not complete because a button or mockup exists.
